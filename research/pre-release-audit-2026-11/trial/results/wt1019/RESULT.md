## Method notes
Concurrency and failure were the productive dimensions: tracing the session's close order against the lock gave the main finding, and walking the fallible calls in order gave the orphan and the partial-cascade findings. Environment and resources added little on a local-socket filesystem change. Wiring was confirmed quickly because binary tests exist. The "one more" step (live observers of shared state) did produce something real: it is what led to the feed-broadcast gap, which none of the nine dimensions named directly. I settled the race by reading session.rs close order; I would have run a binary test that deletes during the GRACE window if cargo had been allowed.
