# TUI mock

`index.html` is the owner's HTML mock of Fiber's terminal, "Fiber TUI mock", saved from the claude.ai artifact <https://claude.ai/artifact/HAioLtYnRRg5MYK9GDNBx9>. Open it in a browser. It loads its fonts from Google Fonts and nothing else.

The prototype in `research/tui-prototype` draws what the mock shows in a real terminal, and the built TUI looks like the prototype. A surface the mock already draws is checked against this file. A change to the mock replaces `index.html` in a pull request.
