# Using Fiber

Pages for a person running Fiber as a coding agent, and for the agent that
answers that person's questions about Fiber. They are installed with Fiber,
in `docs/user/` in Fiber home, and published as the website.

Each page links into the area docs in `docs/` for how Fiber works, rather
than restating them. A page for an area is written once that area is built,
not when it is designed.

The first pages are: installing Fiber, `fiber doctor`, logging in, choosing a
model, a first prompt, permissions in one paragraph, and where to get help.
The command reference is generated from Fiber's command definitions.
