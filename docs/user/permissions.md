# Permissions in one paragraph

Every session runs in `auto`, and there is no other mode: each tool call is judged by what that specific call does — reads, writes, executes or network, with reversibility and paths — never by looking at the command string ([The rule everything else follows from](../permissions.md), [One mode](../permissions.md)); a fast path, a session grant or a standing rule allows the call when one matches, and otherwise the reviewer decides, escalating to you on repetition or failure, with a standing deny or the credential deny refusing first ([The order a call is judged in](../permissions.md)). The whole policy, including what to do when a call waits on you, is [Permissions and approvals](../permissions.md).
