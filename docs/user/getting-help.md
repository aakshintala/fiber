# Getting help

Run `fiber doctor` when a session will not start ([fiber doctor](doctor.md)).

## Logs and crash reports

Where each part of Fiber home lives, including the diagnostic logs and the crash reports, is [What each part holds](../state.md). Quote the newest error line and the crash file's age when you ask for help: they say what the last runs left behind.

## Filing an issue

When the guide and the doctor do not get you unstuck, file an issue at [https://github.com/aakshintala/fiber/issues](https://github.com/aakshintala/fiber/issues). Say what you ran, what you expected, and paste the `fiber doctor` output with the newest error line.
