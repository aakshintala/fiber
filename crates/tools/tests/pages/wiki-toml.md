**Tom's Obvious, Minimal Language** (**TOML**, originally **Tom's Own Markup Language**)[[2]](#cite_note-2) is a [file format](https://en.wikipedia.org/wiki/File_format) for [configuration files](https://en.wikipedia.org/wiki/Configuration_file).[[3]](#cite_note-3) It is designed to be easy to read and write by being _minimal_ (unlike the more-complex [YAML](https://en.wikipedia.org/wiki/YAML)) and by using human-readable syntax. The project standardizes the implementation of the ubiquitous [INI file](https://en.wikipedia.org/wiki/INI_file) format, removing ambiguity from its interpretation. Originally created by [Tom Preston-Werner](https://en.wikipedia.org/wiki/Tom_Preston-Werner), the TOML specification is [open source](https://en.wikipedia.org/wiki/Open_source). TOML is used in a number of software projects[[4]](#cite_note-rust-4)[[5]](#cite_note-5)[[6]](#cite_note-6) and has libraries implemented in all popular programming languages.[[7]](#cite_note-7)

## Syntax

[[edit](/w/index.php?title=TOML&action=edit&section=1)]

Among other constructs, TOML's syntax primarily consists of key-value pairs, section names in square brackets, and comments delimited by a leading `#`. TOML's syntax is a superset of the INI format. Contrary to the INI format, which comprises multiple competing variants as a result of ad-hoc parsers, TOML has a formally agreed-upon syntax.

TOML supports the following data types: string, integer, float, boolean, datetime, array, and table.

### Example

[[edit](/w/index.php?title=TOML&action=edit&section=2)]

```
# This is a TOML document.

title = "TOML Example"

[database]
server = "192.168.1.1"
ports = [ 8000, 8001, 8002 ]
connection_max = 5000
enabled = true

# Line breaks are okay when inside arrays
hosts = [
  "alpha",
  "omega"
]

[servers]

  # Indentation (tabs and/or spaces) is allowed, but not required
  [servers.alpha]
  ip = "10.0.0.1"
  dc = "eqdc10"

  [servers.beta]
  ip = "10.0.0.2"
  dc = "eqdc10"
```

## Notable uses

[[edit](/w/index.php?title=TOML&action=edit&section=3)]

TOML is used in a variety of settings, such as:

- [Jekyll](https://en.wikipedia.org/wiki/Jekyll_(software)) (a [static site generator](https://en.wikipedia.org/wiki/Static_site_generator)) configuration `_config.toml` (although configuration through [YAML](https://en.wikipedia.org/wiki/YAML) is also supported)
- [Hugo](https://en.wikipedia.org/wiki/Hugo_(software)) (a [static site generator](https://en.wikipedia.org/wiki/Static_site_generator)) configuration `hugo.toml` (although configuration through [JSON](https://en.wikipedia.org/wiki/JSON) and [YAML](https://en.wikipedia.org/wiki/YAML) is also supported)
- [Python 3](https://en.wikipedia.org/wiki/Python_(programming_language)) package manifests `pyproject.toml`[[8]](#cite_note-8)
- [Rust](https://en.wikipedia.org/wiki/Rust_(programming_language)) package manifests `Cargo.toml`[[4]](#cite_note-rust-4)
- [Julia](https://en.wikipedia.org/wiki/Julia_(programming_language)) project settings `Project.toml` and package manifests `Manifest.toml`[[9]](#cite_note-9)
- [Blender](https://en.wikipedia.org/wiki/Blender_(software)) add-on manifests `blender_manifest.toml`[[10]](#cite_note-10)
- [Gradle](https://en.wikipedia.org/wiki/Gradle) version catalogs `libs.versions.toml`[[11]](#cite_note-11)
- [Mojo](https://en.wikipedia.org/wiki/Mojo_(programming_language)) Config pixi.toml
- [Alacritty](https://en.wikipedia.org/wiki/Alacritty) (a [terminal emulator](https://en.wikipedia.org/wiki/Terminal_emulator)) configuration `alacritty.toml`[[12]](#cite_note-12)
- [Typst](https://en.wikipedia.org/wiki/Typst) package definition `typst.toml` files.[[13]](#cite_note-13)
