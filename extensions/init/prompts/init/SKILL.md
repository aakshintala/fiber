Survey the workspace and write or improve its instruction file through the ordinary `write`/`edit` tools under the ordinary permission review. Work in the session's workspace. If `AGENTS.md` is present, improve it. If both `AGENTS.md` and `CLAUDE.md` are present, improve `AGENTS.md`. Otherwise, if an existing `CLAUDE.md` is present, improve it in place. If neither exists, write `AGENTS.md`.
